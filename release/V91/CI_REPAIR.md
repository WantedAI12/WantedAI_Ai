# V91 CI 계약 정합성 수정

2026-09-17. 아래 변경은 테스트 계약을 현재 배포 구현과 맞추는 작업입니다. 모델, 점수, 안전 기준, 원료, 임계값과 운영 배포는 변경하지 않습니다. 214개 런타임 모듈의 배포본 AST 일치 검사를 유지합니다.

## 확인한 원인

1. `비 온 뒤 숲`은 V89 장면 해석에서 earthy·green·woody로 확장됩니다. CI의 소형 기본 카탈로그는 unchanged 기본 지원 강도 0.35를 만족하는 earthy 원료가 없으므로 계산 전에 거부합니다. 과거 테스트는 이 추가 의미가 없던 시점의 성공 상태를 기대했습니다.
2. 두 V89 테스트는 미채택 실험의 `recovery_seed_score`, 인자를 받는 `recovery_context`, 두 제안 전략 이름을 기대했습니다. 실제 배포본은 `dose_correction_context`와 최종 물리 목적함수 기반 탐색을 사용합니다.
3. 이전 API 테스트는 목표 미달이면 반드시 recipe가 비어 있어야 한다고 가정했습니다. 사용자 요청으로 배포된 V90/V91에서는 유효한 후보 배합을 recipe에도 반환하고, 실제 점수와 목표 미달·승인 여부는 별도로 보존합니다.

## 변경한 검사

- 기존 그린·아쿠아틱 90점 이상 조건은 지원되는 명시적 그린·아쿠아틱·우디 요청에 그대로 적용합니다.
- 원래 비 온 뒤 숲 요청도 유지하며, earthy 의미를 삭제하지 않고 정확한 미지원 축·빈 배합·미실행 시뮬레이션·목표 미달을 반환하는지 별도로 검사합니다.
- 실제 배포 함수로 중첩 요청의 초기 배합 분리와 복원을 검사합니다.
- 물리 재계산에서 나빠진 제안은 거부하고 좋아진 제안은 채택하는 두 경우를 검사합니다. 점수 보정값은 0이어야 합니다.
- API의 JSON/SSE 일치, 캐시 분리, 원래 목표와 실제 점수 보존은 유지합니다. 배합 존재와 목표 달성·승인을 동일하게 취급하지 않도록 검사를 갱신합니다.

이 변경은 새로운 향 재현 성능 개선이나 실측 유사도 입증이 아닙니다. 전체 CI 결과는 해당 커밋의 GitHub Actions 완료 결과를 기준으로 확인해야 합니다.
